# METY | AI-Powered Healthcare Platform

### Collaborative Software Engineering Project | Arizona State University

METY is a healthcare-focused AI application designed to make health-related information easier to access through conversational interfaces and retrieval-augmented generation (RAG).

## The Engineering Challenge

Healthcare applications require more than generating AI responses. They need reliable API integrations, secure authentication, effective information retrieval, and safeguards against inaccurate responses.

METY explores these challenges through an integrated full-stack application.

## Technology Stack

**Backend:** Python, Django REST Framework, PostgreSQL

**Frontend:** React, JavaScript

**AI:** Large Language Models, RAG, Prompt Engineering

**Cloud & Security:** AWS Cognito, JWT Authentication

**Testing:** Pytest, Vitest, React Testing Library

## Key Engineering Features

- REST APIs connecting frontend and backend services
- Authentication and protected application endpoints
- LLM-assisted information retrieval using RAG
- Response validation and fallback handling
- Database-backed application workflows
- Unit and integration testing
